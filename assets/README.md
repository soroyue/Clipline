# Clipline icon

Original Clipline artwork generated with OpenAI image generation; it does not use Tendedero artwork. Used for the app bundle and project documentation.

Design prompt: A native macOS rounded-square icon with an ivory ceramic tile, two hanging cards (warm oatmeal text lines and a mist-blue mountain photo), restrained metal clips and a curved clothesline. No lettering, no third-party branding; transparent outside the tile.

The source PNG is packaged into the standard macOS icon sizes by scripts/build-app.sh.
