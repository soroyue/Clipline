# Security / 安全

Clipboard history may contain sensitive text and is not encrypted. Recognized
privacy markers are filtered, but applications do not always supply them.
剪贴板历史可能包含敏感内容且未加密；来源应用不一定提供私密标记。

Do not post credentials, real clipboard history, personal screenshots or local
logs in public issues. For a vulnerability, use GitHub's private vulnerability
reporting feature on the Security tab when available. If unavailable, open a
minimal issue requesting a private reporting channel, without exploit details
or sensitive data. No response-time guarantee is offered.
请勿在公开 issue 中提交凭据、真实历史、个人截图或本机日志。优先通过 Security 页的私密漏洞报告功能联系；若不可用，仅请求私密沟通渠道，不公开敏感细节。
